# Contributing to Raven

Thanks for your interest in Raven!
This guide also applies to [thestacks](https://github.com/Astera-org/thestacks), the instance of Raven that is deployed by and for the Astera communities.

## How the project is run

Raven and The Stacks are developed by [Astera](https://astera.org).
Our roadmap is driven by the needs of our teams, along with a few partner groups that deploy their own instance of Raven.
The code is openly licensed so that anyone can use and adapt it, but **for now**, we don't run it as a participatory open source project.

Currently, we develop new functionality in a private repository, and periodically push our commits here and publish releases.

Over time, our goal is to open this project more, to do more of our work in public, and to potentially grow this into a more participatory and multi-stakeholder project if the interest is there! However, either way this will take a while.

## This project may evolve rapidly

Raven is best thought of as alpha-stage software.
Its underlying APIs, data formats, and technology stack may change quickly.
See [About Raven](https://docs.thestacks.org/raven/about) for how we expect it to evolve.

## What we welcome

**Issues are your best bet.**
Bug reports, questions, and ideas are all welcome.
We read every issue and will do our best to respond, but we can't promise a timeline.
We aren't accepting pull requests from outside Astera yet.

## Make a change

Note: This section is for Astera team members.

The [developer guide](https://docs.thestacks.org/raven/developers/get-started/) shows how to set up your environment.
Before you open a pull request, run `pnpm lint`, `pnpm typecheck`, and `pnpm test`.

## Report a security issue

Email [support@thestacks.org](mailto:support@thestacks.org) with any security issues!
Please don't open a public issue for a security problem.
