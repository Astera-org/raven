# Administrator guide

(admins:admin-ui)=
The admin UI is a web app for managing a Raven server, such as its organizations, users, and DOI metadata.
Admins log in with their usual username or email and password.

(admins:roles)=
**Site admins** manage the whole server, including creating organizations and managing users.
**Organization admins** manage the settings and members of their own organizations.

Tasks that need database access, like deleting a user account, are in the deployer guide.
