# Raven documentation

Raven is open source software for running a scientific publishing platform on your own infrastructure.
It was developed by [Astera](https://astera.org).
Read [About Raven](./about.md) for more information about the project.

:::{note} Looking for The Stacks?
[The Stacks](https://thestacks.org) is a service that runs its own Raven instance for the Astera and Arcadia communities.
Its guides for readers and authors are in the [The Stacks docs](xref:thestacks).
:::
