# Troubleshooting

Each entry describes a problem, how to fix it, and where to read more.

## I can't comment

You need an account to comment. Click {gui}`Sign up` to create one.
See [](./index.md).

## I can't edit my comment

A comment can only be edited within 1 hour of posting, and not after someone has replied to it.
Post a follow-up comment to correct it instead.
See [](#readers:editing-comments).
