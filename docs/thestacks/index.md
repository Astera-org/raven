# The Stacks documentation

[The Stacks](https://thestacks.org) is an open-access platform for sharing and discovering scientific, technical, and intellectual work.
It runs on [Raven](xref:raven), open source software that any organization can deploy for its own publishing platform.
See [](./about/index.md) for more, and [About The Stacks](https://thestacks.org/about) for the latest on the platform.
